## Project Overview

This repository contains my HTML5 and CSS3 training tasks and projects completed during the GRIDS APPS Full Stack Web Development Internship.

The projects were first developed using HTML5 to practice semantic page structure, forms, tables, images, and navigation links.

Later, CSS3 was added to improve the appearance of each project through colors, spacing, layouts, typography, and responsive design.

The repository also includes a multi-page educational company website for GRIDS APPS.

## Final Project - GRIDS APPS Website

The final project is an educational company website built using HTML5 and styled with CSS3.

It includes 11 connected pages with navigation links, company information, service descriptions, example projects, blog articles, a gallery, and a contact form.

### Website Pages

| Page | Description |
|---|---|
| Home | Company introduction, services, benefits, and testimonials |
| About Us | Company information, mission, and vision |
| Services | Overview of the company's example services |
| Service Detail | Detailed information about web development |
| Portfolio | Sample website, app, and software project ideas |
| Blog | Blog articles about websites and technology |
| Blog Detail | Full article about why businesses need websites |
| Gallery | Example images of different website types |
| Contact Us | Contact information and HTML5 form |
| Privacy Policy | Information about the educational website and contact form |
| Terms & Conditions | Terms for using the educational website |

## How to Run

1. Download or clone the repository.
2. Open the project folder in Visual Studio Code.
3. Open `HomePage/index.html` in a web browser.
4. Use the navigation menu to explore the website.
5. Open any challenge folder to view its HTML and CSS project.

No server or installation is required.
