## Project Overview

This repository contains my HTML5 training tasks and projects completed during the GRIDS APPS Full Stack Web Development Internship.

The training focuses on building web pages using HTML5, understanding semantic structure, creating forms and tables, working with images, and connecting pages using navigation links.

The repository also includes a multi-page educational company website for GRIDS APPS.

## Final HTML5 Project - GRIDS APPS Website

The final project is an educational company website built using HTML5.

It includes 11 connected pages with navigation links, company information, service descriptions, example projects, blog articles, a gallery, and a contact form.

### Website Pages

| Page | Description |
|---|---|
| Home | Company introduction, services, benefits, and testimonials |
| About Us | Company information, mission, and vision |
| Services | Overview of the company's example services |
| Service Detail | Detailed information about web development |
| Portfolio | Sample website, app, and software project ideas |
| Blog | Blog articles about websites and technology |
| Blog Detail | Full article about why businesses need websites |
| Gallery | Example images of different website types |
| Contact Us | Contact information and HTML5 form |
| Privacy Policy | Information about the educational website and contact form |
| Terms & Conditions | Terms for using the educational website |

### Main Website Features

- 11 connected HTML pages
- Semantic HTML5 structure
- Navigation menu and internal links
- Images with alternative text
- Lists and tables
- Blog listing and article details
- Project portfolio and image gallery
- Contact form with HTML5 validation
- Privacy Policy and Terms & Conditions
- Links to page sections
- Back to Top links

**Important:** This is an educational website. The services and projects are examples, not real client work.

The contact form is for training purposes only. It validates the required fields but does not send or save information.

## How to Run

1. Download or clone the repository.
2. Open the project folder in Visual Studio Code.
3. Open `HomePage/index.html` in a web browser.
4. Use the navigation menu to explore the website.
5. Open any challenge folder to view its HTML exercise.

No server or installation is required.
